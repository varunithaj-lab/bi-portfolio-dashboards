This portfolio showcases dashboards, data models, SQL pipelines, and automated analytics solutions I have personally designed and implemented.
All dashboards use non-sensitive placeholder data, and each example demonstrates BI engineering principles such as automation-first design, metric standardisation, reproducibility, and scalable self-service analytics.
Tools & Technologies Used

SQL (Window functions, CTEs, aggregations, data quality checks)

Python (ETL scripting, API ingestion, anomaly detection, trend modelling)

Power BI / Tableau (dashboards built in neutral corporate BI style)

Data Modelling (star schema, semantic layers, KPI definitions)

ETL Pipelines (validation layers, automated refresh logic, scheduling)

Version Control (GitHub for reproducibility)
Purpose:
Provides visibility into compute, storage, and service-level cloud spend to enable optimisation decisions.

Key Metrics:

Total monthly compute cost

Storage cost trend

Cost per service / workload

Forecasted spend (30-day projection)

Decision Impact:
Helps engineering and finance teams reduce unnecessary usage, allocate budget, and prevent cost overruns.
